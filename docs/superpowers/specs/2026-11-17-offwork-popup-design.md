# 下班提醒弹窗改造 · 设计

日期：2026-11-17
范围：`D:\Codes\off-work-clock`（`off_work.py`）

## 1. 背景

当前提醒链路：`schtasks` 一次性任务 → PowerShell → `System.Windows.Forms.NotifyIcon.ShowBalloonTip()`。

问题：

- WinForms 气泡是 Win7 时代的 API，Win11 下只是被托底渲染，外观不可控，署名 "Windows PowerShell"
- 没有交互，`ShowBalloonTip(0)` 用系统默认时长，几秒自动消失，容易错过
- 专注助手开着时可能完全不弹，且没有留下可诊断的痕迹
- 每运行一次就新增 `OffWorkReminder_*` 计划任务，从不清理

## 2. 目标

- 到点提醒**必须点击确认后才消失**，不自动超时
- 外观明显好于 WinForms 气泡：深色圆角卡片、层次清晰
- 去掉一切打扰元素：无提示音、无任务栏闪烁、无动画
- 保持「纯标准库 + 计划任务到点拉起」，不引入常驻进程

非目标：

- 不做常驻托盘、不做重复催促、不做声音
- 不改 8h45m 计算逻辑和现有 CLI 参数

## 3. 交互与外观

```
┌────────────────────────────────┐
│  18:30                         │
│  辛苦一天，该走啦               │
│                                │
│      [知道了]  [10 分钟后再提醒] │
└────────────────────────────────┘
```

- 无边框、无标题栏、深色圆角，固定在**主屏右下角**（工作区内，避开任务栏，边距 24px）
- 配色：卡片 `#26263A`、主文字 `#E8E8F0`、强调色 `#5FD3C4`
- 时间用**原生大字号**（Microsoft YaHei UI，56px），不再用点阵字符：Tk 渲染 `█` 会出现行缝
- 不抢焦点：只用 `-topmost`，不 `focus_force`；不显示在任务栏（`overrideredirect`）

两档提醒：

| | 提前 10 分钟 | 到点 |
|---|---|---|
| 尺寸 | 约 320×96 | 约 380×200 |
| 内容 | "还有 10 分钟下班" + 打卡时间 | 大号时间 + "辛苦一天，该走啦" |
| 按钮 | 无 | 知道了 / 10 分钟后再提醒 |
| 消失 | **30 秒**后自动关，点一下也关 | 只能点确认（Alt+F4 / X 等同确认） |

> 提前提醒从 10 秒改为 30 秒：10 秒太短，正是"一闪就没"的老问题。

## 4. 触发与调度

- 仍用 `schtasks` 一次性任务，动作改为：
  `<pythonw.exe> "<off_work.py>" --fire main --clock 18:30`
- `pythonw.exe` 用绝对路径 `Path(sys.executable).with_name("pythonw.exe")`（不闪黑窗）；
  找不到时回退 `python.exe`
- 任务加 `/it`：只在用户登录时交互运行，否则窗口没有桌面会话可画
- 提前提醒时间：下班前 **10 分钟**（原为 5 分钟）
- 排程前清理上次记录的任务：状态文件 `.state.json` 保存任务名，下次运行逐个
  `schtasks /delete /tn <name> /f`

## 5. 文件结构

- `off_work.py`：计算 + 排程 + `--fire` 入口；`--fire` 调 `popup.run_popup()`，
  返回 `snooze` 时就地新建 "10 分钟后" 的任务
- `popup.py`：只负责画卡片，暴露 `run_popup(kind, clock_text) -> "ack" | "snooze"`
- 预览：`python popup.py --kind main --clock 18:30`

## 6. 失败处理

- `--fire` 全程 `try/except`，异常和时间戳写 `%TEMP%\off_work.log`
- `tkinter` 导入失败或建窗失败 → 回退到现有的气球通知（提醒不丢）
- 计划任务本身创建失败 → 在终端明确报错（现有行为保留）

## 7. 测试

手动验收：

1. `python popup.py --kind main --clock 18:30`：位置、配色、按钮点击、Alt+F4
2. 建一个 2 分钟后的任务：`pythonw` 无黑窗，卡片正常出现
3. 点「10 分钟后再提醒」→ `schtasks /query` 能看到新任务
4. 连续运行两次 → 上一次的任务被清理，不累积
5. 提前提醒卡：30 秒自动消失；点击可提前关
6. 锁屏期间到点：解锁后卡片应在原会话中可见（不符合则记入日志再定）
